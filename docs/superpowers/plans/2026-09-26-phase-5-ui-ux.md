# Phase 5 — Refonte UI/UX : plan d'implémentation

> **For agentic workers:** superpowers:executing-plans (inline). Checkbox steps.

**Goal :** réparer les cartes (shadcn-map), rendre visibles les features cachées (Progression),
refondre la navigation, réparer les classements, retirer le factice des paramètres et donner un
rôle à chaque panneau droit — en polissant l'identité actuelle avec des composants shadcn.

**Périmètre validé (26/09/2026)** : backlog P1 + « panneaux droits utiles » de
`docs/audit/features-pages.md`. Direction visuelle : garder et polir, composants shadcn en
priorité. **Point de validation** : captures envoyées à l'utilisateur après la Task 7, avant
toute suite.

**Hors périmètre** : réactions / social, objectif hebdomadaire, `/compare`, profil enrichi (hors
panneau), photo de profil (pas de stockage de fichiers), changement d'e-mail (pas de service
d'envoi d'e-mails pour la vérification).

## Global Constraints

- Composants : `pnpm dlx shadcn@latest add <x>` (dossier `src/components/shadcn-ui/`), jamais de
  réimplémentation d'un composant shadcn existant. Skill `shadcn` à consulter.
- Pas de nouvelle couleur hors tokens du thème, sauf données (graphiques, tracé `#10b981`).
- Leaflet ne tourne pas côté serveur : carte chargée via `next/dynamic` (`ssr: false`) dans un
  composant client.
- Tests en navigateur sur la branche Neon `dev-refonte`, desktop 1440 px et mobile 390 px.
